1. CORE PURPOSE
===============

Signal 75 is a fully automated UK horse-racing selection, validation, and continuous learning system.

The goal is not to pick every winner.

The goal is to identify repeatable structural edges using Betfair historical and live data, filter weak bets, and maintain a fully transparent public record.

Core principles:

- Honest: publish every result including losses.
- Cautious: no-bet days are a feature, not a bug.
- Evidence-led: every decision should be traceable to data.
- Transparent: public proof must be clear and conservative.
- Adaptive: failures should improve the future engine.
- Sustainable: protect bankroll and trust above all.

Core phrase:

"Every Race. Every Runner. Every Result."

3. CURRENT SCORING SYSTEM
=========================

Base score:

60

Current scoring factors:

1. Odds band
2. Race type
3. Course profile
4. Horse historical profile
5. Recent form
6. Days since last run
7. Field size
8. Betfair market confidence
9. Chester draw penalty where relevant

Scores are normalised so they do not inflate into unrealistic 130-150 ranges.

Approximate score meaning:

- 65+ = radar/watchlist possible
- 75+ = official consideration
- 82+ = strong
- 88+ = banker-level score

Historical data currently includes approximately:

- 3.49m settled Betfair runner records
- 296,977 horse profiles
- 482 course profiles
- 22 race type categories
- 8 odds bands


4. CURRENT OFFICIAL PICK RULES
==============================

Official picks must pass all current gates:

1. Signal 75 score 75+
2. Odds between 4.1 and 6.0
3. Field size 8+
4. Named tipster support required
5. One horse per race
6. Maximum three official picks per day

Tipster-first rule:

1. Try horses with 3+ named tipsters.
2. If none qualify, try horses with 2+ named tipsters.
3. If none qualify, try horses with 1+ named tipster.
4. If none pass the Signal 75 gates, publish no official picks and show radar/watchlist only.

Important:

Tipster support alone does not make an official pick.

The horse still needs to pass Signal 75 value, score, field-size, and race separation rules.


5. RADAR / WATCHLIST
====================

Radar is not official proof.

Radar can show horses that:

- score 65+
- have odds between 2.1 and 12.0
- have tipster support but fail official gates
- have strong Signal 75 scores but insufficient tipster support
- may become interesting after late market movement

Radar should show finishing positions when available.

Radar should include a "why missed" reason.


6. PROOF RULES
==============

Only official public picks count toward proof.

Do not count:

- radar horses
- shadow consensus horses
- late-market shadow horses
- rejected horses
- tipster-only alert horses

Do not mark unresolved races as lost.

Unresolved races remain pending until a later evening result run or morning resolve can settle them.

Each official day is based around a 3-horse each-way Patent:

- 3 singles
- 3 doubles
- 1 treble
- each-way doubles this to 14 bet lines
- 50p each-way = £7 total stake

Proof should show:

- winners
- win rate
- place rate
- patent profit
- ROI
