Signal 75 legacy/manual scripts
================================

These scripts are kept for reference only. They are not part of the active
daily Signal 75 pipeline.

Do not schedule or run these automatically unless they are reviewed first.

Files
-----

- `fill-picks-to-three.py`
  Legacy helper that forced Flat/Jumps cards up to three by adding radar horses.
  This conflicts with the current no-forced-third-pick rule.

- `fetch-results-betfair.py`
  Older results updater. The active results path is `scripts/update-results-mac.py`.

- `june14-idea-lab.py`
  Historical June 14 review/research script. Useful as reference, but obsolete
  as a recurring daily job.
