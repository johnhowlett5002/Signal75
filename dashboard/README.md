# Signal 75 Intelligence Dashboard

This is a read-only local dashboard for understanding Signal 75 picks,
tipster intelligence, learning, and automation health.

It deliberately does not run on the public GitHub Pages site. The live
dashboard feed is written to `dashboard/data/`, which is ignored by Git and
served only on this Mac at `http://127.0.0.1:8750/`.

The normal morning picks and nightly learning jobs refresh the local feed.
It does not change scoring, picks, settlement, proof, or public site data.
